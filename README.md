# Task calendar

Задачи внутри Obsidian: вкладка с календарём месяца и списком задач под ним. Каждая задача - отдельная
заметка со свойствами: её видно и правят в штатной панели свойств Obsidian.

Версия 1.0.1. Требуется Obsidian 1.6 или новее. Работает и на телефоне.

## Как открыть

| Что | Где | Команда |
|---|---|---|
| Список задач с календарём | вкладка в основной области | **Task calendar: Открыть список задач**, иконка календаря на левой панели (на телефоне - в меню иконок) |

## Настройки

| Настройка | Что делает |
|---|---|
| Папка для новых задач | Куда кладутся задачи, созданные из списка. `/` - корень хранилища. Нет такой папки - создаётся при первой задаче |
| Календарь в списке | Выключено (по умолчанию): клик по дню календаря показывает задачи этого дня. Включено: день не выбирается, под календарём - 100 ближайших невыполненных задач и сворачиваемая группа «Выполнено». Переключается на лету |

Задачи ищутся по всему хранилищу, во всех папках. Ни имя файла, ни папка на это
не влияют: задачей заметку делает свойство `Задача`.

## Формат задачи

Задача - заметка с именем по времени создания, `ГГГГММДД_ЧЧММСС.md`, например
`20261113_130215.md`, и со свойствами:

```yaml
---
Задача: Купить молоко
Выполнено: false
Дата и время: 2026-11-13T08:00:00
Дата выполнения:
Повтор: Каждый день
Дата переноса:
Подзадача-1: Проверить срок
Подзадача-1-выполнено: false
Подзадача-1-1: Посмотреть дату на крышке
Подзадача-1-1-выполнено: false
---
```

| Свойство | Что значит |
|---|---|
| `Задача` | текст задачи. Без него заметка задачей не считается |
| `Выполнено` | галочка самой задачи |
| `Дата и время` | день и время задачи, ставятся при создании. От дня считается повтор, по дате и времени идёт список |
| `Дата выполнения` | дата и время выполнения, ставит плагин, когда отмечено всё - задача и все подзадачи |
| `Повтор` | правило повтора словами, см. «Повторы». Пусто - задача разовая |
| `Дата переноса` | дата и время, на которые перенесли повторную задачу |
| `Подзадача-N`, `Подзадача-N-выполнено` | текст и галочка N-й подзадачи, всегда парой. Номер через дефис - вложенная подзадача: `Подзадача-1-2` внутри `Подзадача-1` |

- Задача показывается на дне из `Дата и время`: заголовок карточки, день в
  календаре, точка и просрочка. `Дата переноса` на это не влияет.
- Выполнена та задача, у которой есть `Дата выполнения`.
- Подзадачи идут по номеру. Удалили пару из середины - плагин перенумерует
  остальные подряд: 1, 3, 4 становятся 1, 2, 3.
- Подзадачи бывают вложенными, на любую глубину: `Подзадача-1-1`,
  `Подзадача-1-2` - внутри первой, `Подзадача-1-2-1` - внутри `1-2`. В карточке
  это вложенный список:

  ```
  - [ ] Главная задача
    - [ ] Подзадача-1
      - [ ] Подзадача-1-1
      - [ ] Подзадача-1-2
  ```

  Нумерация чинится на каждом уровне, вложенные переезжают вместе с родителем.
  Задача выполнена, когда отмечено всё, на всех уровнях.
- Все три даты - `Дата и время`, `Дата выполнения`, `Дата переноса` - со
  временем, `ГГГГ-ММ-ДДTЧЧ:ММ:СС`, так их пишет сам Obsidian; без секунд и одним
  днём (тогда полночь) тоже читаются. Плагин сам назначает типы: датам - «Дата и
  время», «Выполнено» - «Флажок»: в панели свойств у них выбор даты и галочка,
  даже когда значение пока пустое.
- Имя файла задаётся один раз при создании и на даты не влияет.
- До 14.11.2026 свойство называлось `Дата` и хранило только день. Старое имя
  плагин больше не читает.
- Текст под свойствами плагин не читает и не трогает: там можно держать заметки
  к задаче.
- Имя файла задаётся один раз и дальше не меняется.

## Список задач

Сверху всегда календарь месяца, под ним карточки одним списком. Что в списке,
решает настройка «Календарь в списке»:

- **выключена** (по умолчанию) - задачи выбранного в календаре дня, см.
  «Задачи дня»;
- **включена** - день в календаре не выбирается, под ним 100 ближайших
  невыполненных задач: всегда первыми просроченные (и те, что перенесли на
  прошедший день), дальше по `Дата и время`, раньше выше. Задачи без даты - в
  самом низу. Под ними группа «Выполнено»: сверху только что выполненные (по
  `Дата выполнения`, новее выше), видны 20 карточек, а число у заголовка - все
  выполненные. Группа сворачивается кликом по заголовку и остаётся свёрнутой
  после перезапуска.

У карточки сверху день показа («Суббота 14 июля», год - только если не текущий)
и кнопка редактирования - она открывает файл
задачи. Ниже галочка задачи и подзадачи с отступом. Галочка в карточке пишет
свойство в файл, а на телефоне ещё и отзывается короткой вибрацией; ссылки в
тексте работают как в заметке.

Повторяющаяся задача в списке одна: её будущие дни видны только точками в
календаре.

### Новая задача

Кнопка «+» прилипает к низу вкладки. Она сразу создаёт файл задачи в папке для
новых задач и открывает его: в `Дата и время` - сегодня, 08:00,
`Выполнено: false`, остальные свойства пустые и заполняются руками в панели
свойств. Пока `Задача` пустая, файл задачей не
считается и в списке его нет; заполнили - карточка появилась.

## Повторы

```
кажд<окончание> [<N>] <единица> [[в] <список>]
```

Регистр и падежи не важны, число с единицей согласовывать не обязательно: «каждые
2 дня» и «каждый 2 день» - одно и то же. Без числа `N = 1`.

| Единица | Как писать |
|---|---|
| день | день, дня, дней, дни |
| неделя | неделя, неделю, недели, недель, неделе |
| месяц | месяц, месяца, месяцев, месяцы |
| год | год, года, году, годов, годы, лет |
| дни недели | понедельник, вторник, среда/среду, четверг, пятница/пятницу, суббота/субботу, воскресенье |
| месяцы | январь/января/январе и так же остальные |

Список после единицы пишется с «в» или без него. Он уточняет **только свою
единицу**: дни недели - неделю, месяцы - год. Перечислять можно через запятую
или «и».

```
Каждый день
Каждый 2 день
Каждую неделю Суббота, Воскресенье
Каждую 2 неделю в Понедельник, Среду
Каждый 2 месяц
Каждый год Июль, Август
```

Не принимаются: `Каждый месяц Суббота`, `Каждый день в Субботу`,
`Каждую неделю Март`. Задача с нераспознанным повтором остаётся видна как
обычная, только без повтора.

Понимаются и короткие формы: `Ежедневно`, `Еженедельно`, `Ежемесячно`,
`Ежегодно`, `Каждую субботу` (= каждую неделю в субботу), `Каждый март`
(= каждый год в марте), `каждый 2-й день`.

### Какой день будет следующим

База - **день из `Дата и время` выполненной задачи**, шаг применяется один раз. Ни дата
выполнения, ни сегодняшний день в расчёте не участвуют.

| Повтор | Правило |
|---|---|
| день, N | база + N дней |
| неделя, N, без дней | база + 7×N дней |
| неделя, N, дни D | ближайший день из D после базы внутри её недели, иначе неделя базы + N недель |
| месяц, N | база + N месяцев, число сохраняется (31 -> 28/29/30) |
| год, N, без месяцев | база + N лет (29 февраля -> 28 февраля) |
| год, N, месяцы M | ближайший месяц из M после базы в том же году, иначе год базы + N |

**Следствие:** задача, закрытая с опозданием, получает следующую дату тоже в
прошлом и сразу оказывается просроченной. Ежедневная с днём 2026-08-01,
закрытая 20 августа, получит день 2026-08-02. Долги закрываются по одному
дню - это задумано, догонять до сегодня плагин не будет.

## Выполнение

Откуда поставлена галочка - из карточки или в панели свойств, - неважно.

| Что случилось | Что делает плагин |
|---|---|
| Отмечено всё: задача и все подзадачи | ставит `Дата выполнения` - сегодня, со временем отметки до минуты (секунды `:00`). Есть повтор - очищает `Повтор` и создаёт файл следующего повтора |
| Снята любая галочка у выполненной | очищает `Дата выполнения`. Повтор не возвращается: задача становится обычной |

Файл следующего повтора ложится **рядом с выполненным**, в ту же папку: то же
`Задача`, `Дата и время` - день по повтору и 08:00, тот же `Повтор`, те же подзадачи со снятыми
галочками.

## Перенос на другой день

Перенос делается правкой свойств:

- **разовая задача** - поменяйте `Дата и время`; `Дата переноса` у неё ни на
  что не влияет;
- **повторная** - впишите `Дата переноса` (день и время). Плагин скопирует её
  целиком в `Дата и время` задачи - по ней задача встанет в список и
  календарь, - очистит `Повтор` и создаст файл следующего повтора от исходного
  дня. Если следующая дата совпала с днём переноса, берётся следующая за ней.

```
Было:    20261110_090000.md   Дата и время: 2026-11-14T08:00:00  Повтор: Каждую неделю Суббота
Вписали Дата переноса: 2026-11-15T19:30:00 ->
         20261110_090000.md   Дата и время: 2026-11-15T19:30:00  Дата переноса: 2026-11-15T19:30:00  Повтор: (пусто)
         20261113_130215.md   Дата и время: 2026-11-21T08:00:00  Повтор: Каждую неделю Суббота
```

## Календарь

Календарь стоит сверху списка задач: сетка месяца, листание месяцев, подсветка
сегодня. Отдельного календаря в боковой панели больше нет: если его вкладка
осталась с прошлого запуска, плагин её закроет.

Точка на дне - есть невыполненная задача на этот день или на него приходится
будущий день повтора. До дня повторной задачи точек нет: её тогда ещё не было.

### Задачи дня

При выключенной настройке «Календарь в списке» день в календаре выбирается
кликом (сначала выбран сегодня), а под календарём - задачи выбранного дня,
подряд и без заголовков:

- сначала просроченные (красная рамка) - видны в любой выбранный день, чтобы о
  долге не забыть;
- дальше задачи с этим днём показа и повторные задачи, у которых на него
  приходится день повтора (там, где у календаря точка), а в конце - выполненные
  с этим днём показа. Внутри каждой части - по `Дата и время`, раньше выше.
  Отмеченная карточка поэтому уезжает в конец дня.

На пустом дне - «Задач нет». Задачи без даты в этом режиме не видны. Дня в
заголовке карточки нет - он выбран в календаре. Выбранный день в новый файл не
пишется. Галочка на карточке повторной задачи в её будущий день закрывает саму
задачу.

## Чего плагин не делает

- не читает прежние форматы и не переносит из них задачи: строки
  `- [ ] ... 📅 ...` версий до 1.0.1 и блоки 3.0 больше не подхватываются,
  нужные задачи заводятся заново;
- не догоняет правки, сделанные при выключенном плагине: отметили всё, пока он не
  работал, - `Дата выполнения` появится только после следующей галочки;
- не чинит то, что написано руками: `Дата выполнения` при снятых галочках,
  дата вне повтора - всё остаётся как есть;
- не догоняет пропущенные повторы до сегодняшнего дня.

## Разработка

Vue 3 + TypeScript, сборка esbuild в один `main.js`, тесты на vitest.

```bash
npm install --legacy-peer-deps   # флаг обязателен: конфликт peer-зависимостей vite и vitest
npm test                         # 257 тестов
npm run typecheck                # tsc -noEmit
npm run dev                      # watch-сборка main.js на месте
npm run build                    # typecheck + прод-сборка в dist/
```

Нужен Node 18 (из-за него vite остаётся на 5, а vitest на 2). Чтобы правки увидел
Obsidian, нужен `npm run dev` или `build` с копированием `dist/main.js` в корень
плагина: Obsidian грузит собранный `main.js`, а не исходники.

| Файл | Что внутри |
|---|---|
| `src/TaskCalendarPlugin.ts` | класс плагина: карта, вид списка, команды, настройки, закрытие старой вкладки календаря |
| `src/taskFormat.ts` | формат целиком: свойства, грамматика повтора, расчёт дат, автоматика, порядок списка |
| `src/taskMap.ts` | индекс над файлами и API на запись: галочка, файл новой задачи, файл повтора |
| `src/components/TaskList.vue` | список: календарь сверху, под ним задачи выбранного дня или 100 ближайших невыполненных и группа «Выполнено», карточки, кнопка новой задачи |
| `src/components/TaskCalendar.vue` | календарь: сетка, точки, выбор дня |
| `src/components/TaskBody.vue` | рендер тела карточки, ссылки и чекбоксы |
| `src/haptics.ts` | вибрация на галочке на телефоне |
| `test/` | 257 тестов, подробности - в `test/README.md` |
